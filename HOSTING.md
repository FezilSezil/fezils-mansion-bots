# 24/7 хостинг ботов (без твоего компьютера)

Код уже готов к этому: `start.js` запускает оба бота (`review_bot.js` + `post_announcer.js`) в одном
процессе, токен/вебхук берутся из переменных окружения хостинга — clipboard-подхват и открытие браузера
теперь просто отключаются на не-Windows машине, так что на сервере ничего не зависнет.

Я не могу завести тебе аккаунт на хостинге сам (это единственное, что тебе придётся сделать руками) —
дальше всё делается за 5 минут.

## Railway (рекомендую — проще всего)

1. Зайди на **railway.app** и зарегистрируйся (через GitHub-аккаунт быстрее всего).
2. У себя на компе в папке `discord-bot` открой терминал и поставь Railway CLI:
   ```
   npm install -g @railway/cli
   ```
3. Войди и создай проект:
   ```
   railway login
   railway init
   ```
   (login откроет браузер — просто подтверди)
4. Задай переменные окружения (замени на свои значения):
   ```
   railway variables set DISCORD_TOKEN=токен_бота
   railway variables set DISCORD_WEBHOOK_URL=ссылка_вебхука_announcement
   ```
   Остальные (`BOOSTY_BLOG`, `PATREON_URL`, `REVIEWS_CHANNEL_ID` и т.п.) не обязательны — в коде уже
   стоят твои значения по умолчанию, трогать не нужно.
5. Залей и запусти:
   ```
   railway up
   ```
6. Смотри логи, чтобы убедиться что всё ок:
   ```
   railway logs
   ```
   Должно быть: «Бот отзывов запущен как Fezil's Mansion#3242» и «Слежу за Boosty... Patreon...».

После этого можно закрывать консольные окошки на своём ПК и выключать его — боты продолжат работать
на Railway. Бесплатного лимита Railway (500 часов/мес + $5 кредита) с запасом хватает на пару лёгких
ботов вроде этих.

## Что в архиве для деплоя

- `start.js` — точка входа (запускает оба бота)
- `review_bot.js`, `post_announcer.js` — сами боты (без изменений в логике, только на headless готовы)
- `package.json` — зависимости и `npm start`

`.env` с реальным токеном не заливай никуда и не коммить в git — все секреты только через
`railway variables set` (или Variables в веб-панели Railway).
